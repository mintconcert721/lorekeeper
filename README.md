# 로어키퍼

휴대폰 브라우저에서 Claude와 대화하며 세계관과 캐릭터 설정을 만들고, 설정집으로 정리·관리하는 웹앱입니다. 서버 없이 `index.html` 한 파일로 동작하며, 사용자가 입력한 Claude API 키로 Anthropic API를 직접 호출합니다.

## 기능

- **대화**: Claude가 대화 중 확정된 설정을 설정집에 저장하고, 추가·수정·관계 연결 내역을 보여 줍니다.
- **대답 추천**: 답변마다 다음 대답 후보가 버튼으로 나옵니다. 눌러서 바로 보내거나(✎로 고쳐서 보내기), 여러 개를 골라 한 번에 답할 수 있습니다.
- **파일 첨부**: 이미지(사진 촬영 포함), PDF, 텍스트 파일(.txt .md .csv .json)을 클립 버튼, 붙여넣기, 끌어다 놓기로 첨부합니다. 보내기 전에 파일마다 예상 토큰과 비용이 보입니다. 큰 이미지는 긴 변 1568px JPEG로 줄여서 보내고, EUC-KR로 저장된 한글 텍스트도 읽습니다.
- **설정집**: 세계 개요(전제, 분위기, 규칙)와 인물·장소·세력·종족·사건·사물·개념 항목을 분류번호(C-001 등)로 관리합니다. 검색, 직접 편집, 관계 편집, 수정 이력과 되돌리기, 휴지통을 지원합니다.
- **설정**: API 키, 모델(Opus 5.5 / Sonnet 5.5 / Haiku 5.5), 생각 깊이, 사용 비용 추정, 백업 내보내기/불러오기, Markdown 내보내기.

## 사용법

1. 이 페이지를 휴대폰에서 열고 홈 화면에 추가합니다.
2. 설정 탭에 Claude API 키를 넣습니다. Console(platform.claude.com)에서 이 앱 전용 키를 만들고 월 사용 한도를 걸어 두기를 권합니다.
3. 새 세계관을 만들거나 예시 세계관을 불러와 대화를 시작합니다.

## 데이터와 보안

- API 키와 모든 데이터는 그 기기 브라우저 저장소(localStorage, IndexedDB)에만 저장됩니다. 키는 Anthropic API로만 전송됩니다.
- 브라우저 데이터를 지우면 사라지므로 설정 탭의 "전체 백업 내보내기"로 자주 백업하세요.
