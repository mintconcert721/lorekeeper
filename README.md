# 로어키퍼

휴대폰 브라우저에서 Claude와 대화하며 세계관과 캐릭터 설정을 만들고, 설정집으로 정리·관리하는 웹앱입니다. 서버 없이 `index.html` 한 파일로 동작하며, 사용자가 입력한 Claude API 키로 Anthropic API를 직접 호출합니다.

## 기능

- **대화**: Claude가 대화 중 확정된 설정을 설정집에 저장하고, 추가·수정·관계 연결 내역을 보여 줍니다.
- **대답 추천**: 답변마다 다음 대답 후보가 버튼으로 나옵니다. 눌러서 바로 보내거나(✎로 고쳐서 보내기), 여러 개를 골라 한 번에 답할 수 있습니다.
- **파일 첨부**: 이미지(사진 촬영 포함), PDF, 텍스트 파일(.txt .md .csv .json)을 클립 버튼, 붙여넣기, 끌어다 놓기로 첨부합니다. 보내기 전에 파일마다 예상 토큰과 비용이 보입니다. 큰 이미지는 긴 변 1568px JPEG로 줄여서 보내고, EUC-KR로 저장된 한글 텍스트도 읽습니다.
- **설정집**: 세계 개요(전제, 분위기, 규칙)와 인물·장소·세력·종족·사건·사물·개념 항목을 분류번호(C-001 등)로 관리합니다. 검색, 직접 편집, 관계 편집, 수정 이력과 되돌리기, 휴지통을 지원합니다.
- **관계도**: 항목과 관계를 그래프로 봅니다. 끌어서 이동, 두 손가락으로 확대·축소, 항목을 끌어 자리 고정(위치는 저장됨). 항목을 누르면 연결된 관계와 이름이 강조되고, 카드에서 자세히 보기, 관계 잇기, 주변 1~2단계만 보기, 대화로 이어 가기를 할 수 있습니다. 종류 필터(색 범례 겸용), 검색, 화면 맞춤, 다시 배치를 지원합니다.
- **인물 깊이**: 인물 항목 화면에 기본 · 내면 · 성장 · 말투 · 외모 · 능력 탭이 생깁니다. 탭마다 직접 편집하거나 'Claude와 채우기'로 새 대화를 열 수 있습니다.
  - **내면 엔진**: 원하는 것, 진짜 필요한 것, 상처, 믿고 있는 거짓말, 두려움, 비밀. 상처 → 거짓말 → 원하는 것 ↔ 필요한 것의 흐름으로 보여 줍니다.
  - **성장 곡선**: 이야기 시점마다 모습, 믿음, 바뀐 계기(사건 연결), 처지(-5~5)를 적으면 곡선 그래프로 그립니다. 그 시점의 나이도 보이고, 변화가 거의 없으면 알려 줍니다.
  - **말투 카드**: 어조·말씨, 말버릇, 자주 쓰는 표현, 절대 쓰지 않는 말, 예시 대사. Claude가 대사와 인터뷰에서 따릅니다.
  - **외모 카드·그림 프롬프트**: 키·체격, 얼굴, 머리 등 외모 칸, 무드보드(그림 12장까지), 그림 생성 도구용 영어·한국어 프롬프트 만들기(스타일 선택).
  - **능력과 대가**: 능력마다 한계, 약점, 대가. 대가가 없으면 표시하고, 세계 규칙과 맞는지 Claude에게 점검받을 수 있습니다.
- **호칭표**: 관계·지도 탭의 '호칭'에서 누가 누구를 뭐라고 부르는지(반말·존댓말 등)를 표로 봅니다. 칸을 눌러 양쪽을 함께 고치고, 관계는 있는데 호칭이 없는 쌍과 한쪽만 정한 쌍을 알려 줍니다.
- **비교**: 같은 분류의 항목 2~4개를 나란히 보고, 같은 값은 '겹침'으로 표시합니다. 인물은 기본 정보·종족·직위·지금 나이·속성·내면·말투·외모·능력·서로 부르는 말, 종족은 수명·생물·사회·문화·언어·분포·서로 혼혈, 세력은 직위·정원·구성원 종족·서로를 보는 눈, 사건은 전말·참여자·원인·결과, 사물은 사물 카드·마법 물건·지금 가진 이·재료, 장소와 마법은 카드 칸을 비교합니다. 설정집의 '비교'나 항목 화면의 '비교'에서 엽니다.
- **등장 비중**: 원고함과 대화에서 인물이 나온 횟수, 마지막 언급, 설정 깊이를 보여 주고, 오래 안 나온 인물·한 번도 안 나온 인물·비중에 비해 설정이 얇은 인물을 알려 줍니다.
- **인물 일관성 검사**: 인물 화면의 '일관성 검사'를 누르면 Claude가 원고 속 언행이 성격·내면·말투·호칭·나이·능력과 어긋나는 곳을 인용과 함께 찾아 줍니다.
- **장소**: 장소 항목 화면에 기본 · 사람들 · 경제 · 소문 · 기후 · 일어난 일 탭이 생깁니다.
  - **장소 계층**: 대륙 › 나라 › 도시 › 구역 › 건물처럼 '상위 장소'를 정하면 항목 위에 경로가, 아래에 하위 장소가 보입니다. 설정집의 '장소 계층'에서 트리로 봅니다(순환은 막습니다).
  - **사람들·경제·소문·기후**: 인구, 주민, 언어, 다스리는 자, 특산물, 교역, 물가, 생업, 위험. 소문은 참·거짓·모름으로 표시합니다. 기후는 계절별로 적고(계절 이름은 세계관마다 바꿀 수 있음), '그날의 날씨'로 장면용 날씨 묘사를 만들어 원고함에 저장할 수 있습니다.
  - **이 장소에서 일어난 일**: 이어진 사건(시간순, 관련 인물 포함), 인물, 여기 있는 유물, 이 장소가 나오는 원고를 모읍니다. 하위 장소까지 포함할 수 있습니다.
  - **길과 이동 시간**: 거리 단위와 이동 수단(하루에 가는 거리)을 정하고 장소 사이에 길을 이으면 가장 짧은 경로와 걸리는 날을 계산합니다. 길에 다닐 수 있는 수단을 제한할 수 있고(예: 바닷길은 배만), 지도에 두 장소가 꽂혀 있으면 길이 선으로 그려집니다. 설정 점검이 연표상 너무 빠른 이동을 찾아 줍니다.
  - **지도 위 영역**: 지도에서 꼭짓점을 찍어 나라·세력의 영역을 칠하고, 시작·끝 연도를 넣으면 연도 슬라이더로 국경 변화를 봅니다.
  - **장소 생성기**: 창작 도구(✦)에서 종류·위치·분위기를 고르면 이름 규칙에 맞는 장소(장소 카드, 감각, 소문, 이야기 고리)를 만들어 초안으로 저장합니다.
- **마법**: 개념 항목에서 '마법 체계로 쓰기'를 누르거나 마법 분류의 항목을 열면 체계 · 주문서 · 판정 · 허점 탭이 생깁니다.
  - **마법 체계 설계 카드**: 근원, 쓰는 방법, 대가, 한계, 쓸 수 있는 자, 배우는 법, 실패하면, 금기. 대가와 한계가 비면 강조합니다.
  - **주문서**: 등급, 효과, 대가, 시전 시간, 재료. 등급별로 거르고, 대가 없는 주문을 표시합니다.
  - **규칙 판정**: 상황을 적으면 체계 카드·주문서·판례·관련 인물을 근거로 가능 / 조건부 가능 / 불가능과 대가를 판정합니다. 판례로 저장하면 이후 대화에서 Claude가 따릅니다.
  - **허점 질문**: "이 마법이 있다면 왜 아직 ○○ 문제가 남아 있지?" 같은 질문을 찾아 카드로 보여 주고, 대화로 메우거나 해결함·무시로 정리합니다.
  - **유물 이력**: 사물 항목의 '이력' 탭에서 만든 이와 해, 소유자 이력, 지금 있는 곳과 가진 이, 봉인 상태를 적습니다. 소유 기간이 인물의 생몰년과 맞지 않으면 알려 주고, 있는 곳이 지도에 꽂혀 있으면 지도로 이동합니다.
- **종족**: 종족 항목 화면에 기본 · 생물 · 사회 · 문화 · 언어 · 분포 탭이 생깁니다.
  - **종족 카드**: 생물(체격·외형, 식성, 번식·성장, 타고난 감각, 타고난 능력), 사회(가족 구조, 통치, 계층), 문화(종교·믿음, 예술, 금기, 의례, 복식). 탭마다 직접 고치거나 Claude와 채웁니다.
  - **수명과 나이 환산**: 평균 수명과 단계(유년·성년·노년 등)가 시작되는 나이를 적으면, 그 종족 인물의 나이를 기준 종족의 나이로 바꿔 보여 줍니다(예: 120세 · 성년 · 인간으로 치면 24세 무렵). 기준은 인간(성년 18 · 노년 60 · 수명 80)이고, 세계관마다 다른 종족을 기준으로 바꿀 수 있습니다. 비교표와 생애 겹쳐 보기에도 단계가 나옵니다.
  - **종족 특성 물려받기**: 인물 편집에서 종족을 고르면 인물 화면에 종족 특성이 접혀 보이고, '종족과 다른 점'만 따로 적습니다. 관계로 이어진 종족이 있으면 한 번에 종족으로 정할 수 있습니다.
  - **언어 스케치**: 말소리 특징, 어순·문법 메모, 낱말장('낱말 = 뜻'), 예문. '낱말 만들기'는 이름 규칙과 말소리에 맞춰 기본 낱말을 만들어 더하고(짧은 요청), 다듬기는 대화로 합니다.
  - **분포**: 이 종족이 사는 장소·세력과 비율, 지도의 서식지 영역, 이 종족의 인물을 모읍니다. 장소의 '사람들'과 세력의 '구성' 탭에서 종족 구성 비율을 정하면 막대로 보이고, 설정집의 '구성표'에서 한눈에 봅니다.
  - **혼혈 규칙**: 관계표의 '혼혈' 보기에서 종족 쌍마다 가능 · 드묾 · 불가, 태어나는 아이, 아이의 특성, 사회의 시선을 정합니다.
- **세력**: 세력 항목 화면에 기본 · 직위 · 구성 탭이 생깁니다.
  - **직위 사다리**: 위에서 아래로 직위, 권한, 정원, 그 자리의 인물을 적습니다. 빈자리와 정원 초과가 보이고, 인물 화면에도 직위가 나옵니다.
  - **구성**: 구성원 종족 비율과, 관계나 직위로 이어진 인물을 모읍니다.
- **사건**: 사건 항목 화면에 기본 · 전말 · 경과 · 바뀐 것 · 인과 탭이 생깁니다.
  - **사건 카드(전말)**: 원인 · 경과 요약 · 결과 · 남긴 것과, 참여자마다 역할(주동 · 배후 · 피해 · 목격 · 기타)과 한 일을 적습니다. 관계로만 이어진 인물·세력은 참여자 후보로 보여 줍니다.
  - **세부 경과**: 사건 안의 단계를 시점 표기(예: 1일째 새벽), 내용, 장소로 적고 순서를 바꿉니다. 연표에는 사건 하나로만 보입니다.
  - **바뀐 것**: 사건 기간에 시작·끝난 관계, 태어나고 죽은 인물, 죽은 인물이 맡던 직위, 주인이 바뀐 물건, 생기거나 사라진 지도 영역, 이어진 사건, 남긴 날을 자동으로 모읍니다.
  - **인과 사슬**: 원인·결과 사건을 잇습니다(순환은 막음). 연표 탭의 '인과' 보기는 시간 순서의 흐름도이고, 누른 사건의 원인 쪽·결과 쪽만 밝게 보입니다. 결과가 원인보다 앞서면 빨간 점선으로 표시하고, '없었다면?'은 대화로 엽니다.
  - **기념일·축제 달력**: 연표 탭의 '달력' 보기에서 한 해의 달(정하지 않으면 12달 × 30일)과 기념일 · 축제 · 금기일을 봅니다. 달 이름과 날 수를 고칠 수 있고, 계기가 된 사건과 처음 지킨 해를 적습니다. 달을 바꿔 없는 날짜가 된 기념일은 알려 줍니다.
  - **복선·예언**: 설정집의 '복선' 탭에서 깔린 곳·회수된 곳(항목이나 원고), 예언이 이루어질 해, 상태(깔림 · 회수 · 버림)를 관리합니다. '회수 방법 정하기'는 대화로 이어집니다.
  - **역사 공백 채우기**: 연표의 '… N년 뒤' 표시나 창작 도구에서 빈 구간을 고르면 앞뒤 사건·인물·세력에 맞는 사건 후보를 받고, 고른 것만 초안으로 저장합니다(인과도 함께 이어짐).
- **사물**: 사물 항목 화면에 기본 · 카드 · 이력 · 제작 탭이 생깁니다.
  - **사물 카드**: 외형, 재질, 크기·무게, 쓰임, 가치·값, 희귀도(흔함 · 드묾 · 희귀 · 전설 · 유일), 만드는 법, 지금 상태.
  - **마법 물건**: 마법 체계, 쓸 수 있는 주문(그 체계의 주문서에서 고름), 쓰는 대가, 사용 횟수·충전을 적습니다. 그 체계의 규칙 판정 때 근거로 함께 읽습니다.
  - **소지품**: 인물 화면에 '가진 것'이 나오고, '물건 주기'와 '넘기기'로 유물 이력에 소유 기록을 더합니다(앞 주인의 기록은 그해로 끝남). 같은 해에 두 사람이 한 물건을 가졌다고 되어 있으면 알려 줍니다.
  - **유물 여정 지도**: 소유 기록마다 그때 있던 곳을 적으면, '여정 지도'가 지도 위에 번호와 선으로 여정을 그리고 연도 슬라이더로 그해의 위치를 강조합니다.
  - **제작과 재료**: 재료와 양, 만드는 이, 만드는 곳, 걸리는 시간과, 재료가 나는 곳을 적습니다. 장소의 '경제' 탭에 그곳에서 나는 재료와 '이곳이 막히면 만들 수 없는 것'이 나옵니다.
- **화폐·물가**(설정집): 기준 화폐와 다른 화폐의 값, 쓰는 나라·세력, 물가표(물건, 값, 화폐, 지역)를 정하고 환산 계산기로 바꿔 봅니다. 새 대화의 Claude가 물가표를 따릅니다.
- **기술 수준**(설정집): 지역·시기별로 분야(조명 · 교통 · 통신 · 의료 · 무기 · 인쇄 · 농업 · 건축, 바꿀 수 있음)의 수준을 표로 적습니다. '시대착오 찾기'는 사물·항목·최근 원고에서 표와 어긋나는 곳을 찾아 줍니다.
- **계보(가계도·조직도)**: 관계·지도 탭의 '계보'에서 어머니·아들·배우자·소속·부하 같은 관계로 세대와 위아래를 자동으로 그립니다. 두 부모가 부부면 둘 사이에서 자식 선이 내려옵니다. 관계는 'A의 ○○ = B'로 읽으며, '관계 해석'에서 관계 이름마다 위·아래·같은 줄·쓰지 않음을 고칠 수 있습니다.
- **관계표**: 세력끼리 · 종족끼리 · 인물끼리(또는 직접 고른 분류) 서로를 어떻게 보는지 표로 봅니다. 우호는 초록, 적대·경쟁은 빨강, 정하지 않은 쌍은 ?로 표시합니다. 칸을 눌러 양쪽 관계와 그 기간(부터·까지)을 고치거나, 빈 칸을 Claude와 정할 수 있습니다. 관계에 기간이 있으면 연도 슬라이더로 그해의 관계만 봅니다(예: 300~318년 동맹, 318년부터 적대). 항목 편집의 관계에도 '기간 넣기'가 있습니다. '혼혈' 보기는 종족 사이의 혼혈 규칙표입니다.
- **지도**: 지도 그림(긴 변 2048px로 줄여 저장)을 올리고 장소·세력을 핀으로 꽂습니다. 끌어서 이동, 두 손가락으로 확대, 핀 옮기기·빼기, 지도 여러 장, 그림만 바꾸기(핀 유지)를 지원합니다. 항목 화면의 '지도에서 보기', '대화로'(지도를 첨부해 지리 검토 요청)를 쓸 수 있고, 새 대화를 시작하면 Claude가 핀의 대략적인 위치(북서쪽 등)를 압니다.
- **분류와 템플릿**: 세계관마다 분류(캐릭터, 국가, 마법, 아이템, 고유 명사 등)를 정하고, 분류마다 Markdown 템플릿을 붙입니다. `.md` 파일 여러 개를 한 번에 가져올 수 있고, 예시 템플릿 5종이 들어 있습니다. Claude는 템플릿 구조대로 항목을 쓰고, 직접 만들 때는 템플릿 칸이 미리 채워지며, 항목 화면에 아직 비어 있는 칸이 표시됩니다.
  - **공통 작성 규칙**: 분류·템플릿 관리에서 모든 분류에 함께 적용되는 Claude 작성 안내를 한 곳에 적습니다. 앱이 지금 분류 목록으로 참조 규칙("다른 항목을 참조할 때는 인물 C, 장소 P, …, 신·신격 D의 식별자와 이름을 함께")을 만들어 붙이므로, 분류를 더하거나 이름·코드를 바꿔도 템플릿을 고칠 필요가 없습니다. 이 규칙은 새 대화의 첫 메시지와 Claude가 템플릿을 읽을 때 함께 전달됩니다. '템플릿에서 공통 줄 찾기'는 여러 템플릿에 반복된 작성 안내를 찾아 공통 규칙으로 옮기고, 각 템플릿에서 뺄 수 있습니다.
  - **가져오기 정리**: `.md` 템플릿을 가져올 때 여러 파일에 반복된 작성 안내, 이미 공통 규칙에 있는 줄, 참조 안내 줄(인물 C, 장소 P…)을 찾아 보여 줍니다. 고른 줄은 공통 규칙으로 옮기고 템플릿에서 빼고 가져옵니다.
- **생애 겹쳐 보기**: 연표 탭에서 인물의 생몰년을 가로 막대로 겹쳐 봅니다. 막대 위를 누르면 그해 살아 있던 인물과 나이, 그해의 사건이 나옵니다(◀ ▶로 한 해씩). 시대 띠, '지금' 선, 확대·축소, 세력처럼 기간이 있는 항목 함께 보기를 지원합니다.
- **연표**: 항목에 시점(시작·끝 연도, 표기)을 넣으면 시간순으로 보여 줍니다. 세계관마다 달력 표기(예: 등대력 312년), 현재 연도, 시대 구분을 정할 수 있고, 시대 머리글, '지금' 표시, 인물 나이, 긴 공백 구간이 함께 보입니다. 시점이 없는 사건은 따로 모아 보여 줍니다. Claude도 연표를 읽고 시점을 정리합니다.
- **화면 테마**: 기기 설정 따르기, 라이트, 다크 중에 고릅니다. 위쪽 막대의 해·달 버튼으로 바로 바꿀 수도 있습니다.
- **확정·초안·폐기**: 항목마다 상태를 둡니다. Claude는 확정만 사실로 다루고, 아직 고르지 않은 아이디어는 초안으로 적어 두며, 버린 안은 지우지 않고 폐기로 보관합니다. 폐기된 항목은 연표·관계도에서 빠집니다.
- **설정 점검**: 연표와 어긋난 인물·사건 연결, 버린 항목과의 연결, 이름 겹침, 템플릿 빈 칸, 요약·관계·시점이 없는 항목, 종족 수명을 크게 넘긴 인물, 종족 구성 합이 100을 넘는 곳, 정원을 넘긴 직위, 죽은 뒤에도 직위에 남은 인물, 존재 시기 밖의 관계 기간, 결과가 원인보다 앞선 사건, 그때 살아 있지 않던 참여자, 같은 해 두 사람이 가진 물건, 대가 없는 마법 물건, 회수되지 않은 복선과 때가 지난 예언, 달력에 없는 기념일 날짜를 한 화면에 모읍니다. 세계 규칙 위반 같은 깊은 점검은 Claude에게 맡길 수 있습니다.
  - **점검 센터**(설정 점검 위쪽): 아래 두 점검을 시작하고 지난 보고서를 다시 엽니다. 작품의 구조·연재 점검은 작품 '계획' 탭으로 바로 갑니다.
  - **카테고리 전수점검**: 고른 분류(확정만 또는 확정+초안)의 항목을 묶음으로 나눠 하나도 빠짐없이 Claude가 판정합니다. 항목 안의 모순, 다른 항목과의 모순, 세계 규칙(마법·기술·물가·달력) 위반, 템플릿·공통 작성 규칙, 연표·나이, 비어 있는 핵심 정보, 참조 오류를 근거 문장과 함께 찾습니다. 판정이 빠진 항목은 앱이 다시 보내고, 끝나면 여러 항목에 걸친 문제를 묶어 요약합니다. 시작 전에 '예상 비용'(토큰 계산은 무료)을 볼 수 있고, 세계관 개요·공통 규칙·색인은 프롬프트 캐시로 묶음끼리 재사용해 비용을 줄입니다. 두 번째부터는 '바뀐 항목과 이어진 항목만' 다시 보고 나머지 판정은 이어받습니다.
  - **스토리 전체 점검**: 작품 원고 전체의 연속성(죽은 인물의 재등장, 사물 위치, 알기 전에 앎), 시간선, 인물, 플롯 허점, 회수 안 된 복선, 사라진 가닥, 설정 위반, 계획에서 벗어난 장면, 속도를 봅니다. 원고가 약 12만 토큰 이하면 전문을 한 번에 읽고, 더 길면 장면마다 사실 기록(일어난 일, 누가 무엇을 알게 됐는지, 사물의 움직임, 연 질문·닫은 질문)을 먼저 만든 뒤 전체를 봅니다. 기록은 바뀐 장면만 다시 만들고, 기록에는 Haiku 5.5를 쓸 수 있습니다. 지적마다 '본문으로 다시 확인'으로 해당 장면 원문을 다시 읽혀 잘못된 지적을 거릅니다.
  - **보고서**: 심각도(높음·중간·낮음)·분류·열린 것으로 거르고, 문제마다 해결·무시·되돌리기, 'Claude와 고치기'(새 대화에 문제와 근거를 채움)가 있습니다. 중간에 끊기거나 오류가 나면 '이어서 하기'로 남은 묶음만 보냅니다. 보고서와 장면 기록은 이 기기에만 남습니다(최근 6개, 동기화하지 않음).
  - 참고: Claude의 일괄 처리(Message Batches, 절반 가격)는 브라우저 요청을 받지 않아(CORS 거부) 쓰지 않습니다.
- **창작 도구**(입력창의 ✦ 버튼): 새 대화를 열고 요청을 입력창에 채워 줍니다. 보내기 전에 고칠 수 있습니다.
  - **인물 인터뷰**: 인물이 1인칭으로 답합니다. `(( ))` 안에 쓰면 작가로서 말하고, '인터뷰 정리'를 누르면 새로 드러난 사실을 설정에 넣을지 제안받고 요약을 원고함에 남깁니다.
  - **세계 속 문서**: 편지, 수배서, 경전 구절, 신문 기사, 노래 가사, 포고문, 일기 등을 그 세계 사람이 쓴 것처럼 만듭니다.
  - **N년 뒤 시뮬레이션**: 지금 설정이 흘러가면 어떻게 될지 서로 다른 미래 2~3가지를 씁니다. 새 인물·사건은 초안으로 들어갑니다.
  - **장면 쓰기**, **관점별 서술**(같은 사건을 세력·인물마다 어떻게 기억하는지).
  - **사물 생성기**: 종류·희귀도·문화를 고르면 세계관, 기술 수준, 물가, 이름 규칙에 맞는 사물(카드, 내력, 이야기 고리)을 만들어 초안으로 저장합니다.
  - **역사 공백 채우기**: 구간을 정해 빈 시대의 사건 후보를 받습니다.
- **원고함**: 장면, 세계 속 문서, 시뮬레이션, 인터뷰 기록처럼 설정 항목이 아닌 글을 모읍니다. 종류별로 거르고 검색하며, 직접 쓰거나 고치고, 대화로 이어 쓸 수 있습니다.
  - **작품·장 구조**: 원고함의 '작품' 보기에서 작품 → 장 → 장면 순서로 원고를 묶습니다. 장면 왼쪽 손잡이(≡)를 끌어 순서와 장을 바꾸고, 장면 메뉴(⋯)에서 상태(구상 · 초고 · 퇴고 · 완료), 장 옮기기, 위로·아래로, 작품에서 빼기를 합니다. 작품과 장마다 장면 수, 글자 수, 원고지 매수, 상태별 개수가 보입니다. 장이나 작품을 지워도 장면은 '작품 밖 원고'로 남습니다. 예전 원고는 원고 화면의 '작품에 넣기'로 옮깁니다.
  - **문체 가이드**: 작품 설정에서 시점·시점 인물, 시제, 문장 길이, 문체, 피할 표현, 즐겨 쓸 낱말, 대사 규칙, 예시 문단을 정합니다. Claude가 그 작품의 장면을 쓰고 다듬을 때 따릅니다.
  - **집필 화면**: 화면 전체를 쓰는 편집기입니다. 입력을 멈추면 자동으로 저장하고, 글자 수(공백 포함·제외)와 원고지 매수(200자 기준 대략값), 장·작품 누계를 보여 줍니다. 미리보기, 상태 바꾸기, 앞·뒤 장면으로 넘기기를 지원합니다.
  - **본문 속 설정 인식**: 본문에 나온 항목 이름과 별칭(두 글자 이상)을 찾아 원고 화면에서는 밑줄로, 집필 화면에서는 '등장' 칩으로 보여 줍니다. 누르면 요약 카드가 뜨고, 찾은 항목은 관련 항목에 자동으로 더해집니다. 일반 낱말과 겹치는 이름은 '이 원고에서 무시'로 뺄 수 있습니다.
  - **부분 다듬기**: 집필 화면에서 문단을 고르고 '다듬기'를 누르면 문체 가이드에 맞추기, 짧게, 풍부하게, 감각 묘사 더하기, 대사를 말투에 맞추기, 직접 지시 중에서 골라 다시 쓰게 합니다. 고치기 전과 후를 나란히 보고 '바꾸기'나 '다른 안'을 고릅니다. 문장 품질이 중요해 대화에서 고른 모델로 보냅니다.
  - **원고에서 설정 뽑기**: 원고 화면의 '설정 뽑기'가 설정집에 없는 인물·장소 등, 기존 항목의 새 사실, 깔린 복선을 근거 문장과 함께 찾아 줍니다. 고른 것만 저장합니다. 새 항목은 초안이 되고, 새 사실은 그 항목 본문 끝에 출처와 함께 덧붙고, 복선은 복선 탭에 들어갑니다.
  - **이야기 계획(구조 사다리)**: 작품의 '계획' 탭에서 큰 틀에서 작은 틀로 내려갑니다. ① 한 줄 → ② 한 문단(시작 · 위기 1·2·3 · 결말) → ③ 시놉시스(1쪽) → ④ 장 요약(그 장에서 일어나는 일과 끝나는 지점) → ⑤ 장면 카드 → ⑥ 본문. 단계마다 'Claude로 펼치기'가 바로 위 단계를 근거로 다음 단계를 제안하고, 고쳐서 받아들입니다(장과 카드는 고른 것만 반영, 있는 장·장면과 본문은 지우지 않음). 단계는 비어 있음 · 초안 · 확정 · 다시 볼 것으로 표시되고, 위 단계를 고치면 아래 단계에 '다시 볼 것'이 붙습니다(카드를 고치면 그보다 먼저 쓴 본문도). 진행(장 요약·카드·본문 개수)과 다음에 쓸 장면이 늘 보입니다.
  - **장면 카드·카드판**: 카드에는 요약, 시점 인물, 장소, 때(해·달·날), 등장인물, 목표 → 갈등 → 결과, 반응 → 딜레마 → 결정, 바뀌는 가치와 전환(＋→－ 등), 긴장도(1~5)가 들어갑니다. '카드판' 탭에서 장별로 카드를 보고 손잡이(≡)로 순서를 바꿉니다. 집필 화면 위에 그 장면의 카드가 보입니다.
  - **계획 따라 쓰기**(새 대화부터): Claude는 장면 본문을 쓰기 전에 그 장면의 카드를 찾고, 카드가 없으면 카드부터 제안합니다. 본문은 앞 장면의 결과에서 시작해 이 카드의 결과에서 끝내고, 다음 장면으로 넘어가지 않습니다. 계획에 없는 사건·인물은 본문에 넣지 않고 '계획 밖 아이디어'로 따로 제안합니다. 카드의 '쓰기'(또는 계획 탭의 '이 카드로 쓰기')를 누르면 그 장면을 지목한 요청이 새 대화에 채워집니다.
  - **장면 현황판**: 카드의 때와 장소를 기준으로 설정집에서 그 시점의 세계를 계산해 보여 줍니다(API 비용 없음). 등장인물의 나이와 생애 단계, 지닌 사물, 관련 세력과 그해 관계, 장소의 계절과 기후, 그날의 기념일, 같은 해의 사건, 앞 장면 장소에서 오는 데 걸리는 시간. 아직 태어나지 않았거나 죽은 인물, 이동 시간보다 짧은 장면 간격, 앞 장면보다 이른 때는 '주의'로 알립니다.
  - **구조 점검**: 계획 탭의 '구조 점검'이 계획·카드·본문 발췌·설정을 보고 결말로 이어지는지, 아래 단계가 위 단계에서 벗어났는지, 장면마다 목표·갈등·전환이 있는지, 장면 사이 인과가 이어지는지, 계획 밖 전개가 새어 들었는지 찾습니다(강한 모델). 앱이 바로 찾는 것(빈 장 요약, 빈 카드 칸, 바뀌지 않는 가치, 다시 볼 곳, 현황판의 주의)도 함께 보여 주고, 문제마다 '열기'와 'Claude와 고치기'가 있습니다. 결과는 작품에 남아 '지난 결과'로 다시 봅니다.
  - **연재 도우미**: 작품 설정에서 회차 목표 분량(공백 포함 글자)을 넣으면 장 하나가 한 회차가 되어 'N화'로 표시되고, 회차마다 분량 막대가 보입니다. '연재 점검'은 회차 분량, 회차 끝이 다음 화를 궁금하게 끊기는지, 초반 3화 안에 사건과 주인공의 목표가 나오는지 봅니다. Claude도 연재 작품의 회차를 목표 분량에 맞추고 회차 끝을 끊어 씁니다.
- **감각 사전**: 장소마다 소리·냄새·빛·촉감·맛을 모아 봅니다. 감각이 빈 장소를 알려 주고 Claude에게 채우게 할 수 있습니다.
- **질문 카드**: 하루 세 장씩 생활·음식·의례·법·경제 등 아직 정하지 않았을 영역을 묻습니다. '정했음', '건너뛰기'로 넘기고, 이 세계에 맞춘 질문을 Claude에게 받을 수 있습니다.
- **이름 규칙·이름 생성기**: 나라·종족·가문마다 이름 짓는 규칙을 정하고, 규칙에 맞는 이름을 여러 개 만들어 바로 새 항목으로 만듭니다. Claude도 이름을 지을 때 규칙을 따릅니다.
- **항목 그림**: 항목에 그림을 붙입니다(긴 변 512px로 줄여 저장). 설정집 카드에 작게 보이고, '그림으로 묘사 받기'로 그림을 첨부해 외모·분위기 묘사를 받을 수 있습니다.
- **관점별 서술·감각**: 항목 화면과 편집에서 관점(누가 무엇을 믿는가)과 감각 묘사를 보고 고칩니다.
- **다른 기기와 동기화**: GitHub 비공개 저장소에 데이터를 저장해 여러 기기에서 이어 작업합니다. 두 기기에서 고친 내용을 항목 단위로 합치고, 갈라진 대화는 사본으로 남기며, 지운 것은 다른 기기에서도 지웁니다.
- **짧은 요청은 Haiku 5.5로**(설정 › 모델, 기본 켜짐): 대화와 따로 한 번씩 보내는 요청(이름 만들기, 맞춤 질문, 그림 프롬프트, 그날의 날씨, 장소 생성기, 허점 찾기, 낱말 만들기, 역사 공백 채우기, 사물 생성기, 시대착오 찾기, 원고에서 설정 뽑기)을 값싼 Haiku 5.5로 보냅니다. 판례로 남는 규칙 판정, 원고 부분 다듬기, 대화는 고른 모델을 그대로 쓰고, Haiku가 거절하면 고른 모델로 한 번 더 묻습니다.
- **설정**: API 키, 모델(Opus 5.5 / Sonnet 5.5 / Haiku 5.5), 생각 깊이, 사용 비용 추정, 백업 내보내기/불러오기(원고·그림·지도 포함), Markdown 내보내기(감각·관점·이름 규칙·원고함 포함).

## 사용법

1. 이 페이지를 휴대폰에서 열고 홈 화면에 추가합니다.
2. 설정 탭에 Claude API 키를 넣습니다. Console(platform.claude.com)에서 이 앱 전용 키를 만들고 월 사용 한도를 걸어 두기를 권합니다.
3. 새 세계관을 만들거나 예시 세계관을 불러와 대화를 시작합니다.

## 템플릿 형식

```markdown
---
분류: 국가
코드: N
설명: 나라, 왕국, 공화국
기존분류: 세력
---
- 수도:
- 정치 체제: 군주제, 공화제 등

## 역사
> 건국부터 지금까지 시대순으로
```

- `- 이름: 설명` 줄은 속성 칸이 되고, 설명은 입력 안내로 쓰입니다.
- `## 제목`은 본문 소제목이 됩니다.
- `>`로 시작하는 줄은 Claude에게 주는 작성 안내입니다.
- 맨 위 `---` 사이의 정보(선택)는 가져올 때 분류 이름, ID 코드, 설명을 채웁니다. `기존분류`를 쓰면 그 분류에 템플릿을 붙입니다.

## 대화와 업데이트

한 대화는 시작할 때의 지침과 도구 정의를 끝까지 그대로 씁니다. 앱이 업데이트되어도 진행 중인 대화는 예전 버전으로 이어지고, 새 기능은 새 대화부터 적용됩니다. (지침이 대화 중간에 바뀌면 Claude API가 이전 추론을 무효로 처리하기 때문입니다.)

## 동기화 준비

1. GitHub에서 Private 저장소를 만듭니다(예: `lorekeeper-data`).
2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
3. Repository access: Only select repositories → 방금 만든 저장소. Permissions → Repository permissions → Contents: Read and write.
4. 앱의 설정 → 다른 기기와 동기화에 `아이디/저장소이름`과 토큰을 넣습니다. 다른 기기에서도 같은 값을 넣으면 됩니다.

저장소의 `lorekeeper/` 폴더에 세계관 목록(`index.json`), 세계관별 설정집·원고함·지도 핀(`w/`), 대화별 기록(`c/`), 항목 대표 그림(`i/`), 지도와 무드보드 그림(`m/`)이 저장됩니다. API 키, 모델·테마 설정, 비용 기록은 기기마다 따로입니다.

## 데이터 되살리기

- **저장소 점검·되살리기**(설정 › 백업): 이 기기 저장소에 남아 있지만 세계관 목록에서 빠진 데이터를 찾아 되살립니다. 앱을 열 때 이런 데이터가 있으면 위쪽에 알림이 뜹니다. 저장 공간 사용량과 '저장소 보호'(브라우저가 공간이 모자라도 지우지 않게) 상태도 보여 줍니다.
- **기록에서 되살리기**(설정 › 동기화): GitHub 동기화를 썼다면 저장소에 남은 지난 동기화 기록(최근 30개)을 살펴보고, 그 시점 데이터를 백업 파일로 받거나 이 기기에 되살립니다.
- **백업 불러오기**: 전체 백업 파일(.json)에서 되살립니다. 설정에 마지막 백업 시각이 보입니다.
- 앱을 여는 중 화면 오류가 나도 데이터는 지우지 않고 알림으로 알려 줍니다.
- 동기화는 이 기기 저장소가 비워졌을 때 원격에서 받아 채우고, 삭제 기록 없이 세계관이나 항목이 크게 줄어드는 합치기는 멈춥니다.

## 데이터와 보안

- API 키와 모든 데이터는 그 기기 브라우저 저장소(localStorage, IndexedDB)에만 저장됩니다. 키는 Anthropic API로만 전송됩니다.
- 브라우저 데이터를 지우면 사라지므로 설정 탭의 "전체 백업 내보내기"로 자주 백업하세요.
